# 🎨 Web Design School

## 📌 Project Overview

**Web Design School** was a learning module completed as part of the **100 Days of Python Bootcamp (Day 65)**.

Unlike previous projects, this day focused on **design principles rather than coding**. The goal was to understand how professional websites are planned, structured, and visually designed before implementation.

This module helped develop a better understanding of **UI (User Interface)** and **UX (User Experience)** concepts that are essential for creating modern web applications.

---

# 🎯 Learning Goals

The objectives of this day were:

* Understand the fundamentals of web design.
* Learn principles of visual communication.
* Improve website layout and structure.
* Understand color and typography choices.
* Learn how to create user-friendly experiences.
