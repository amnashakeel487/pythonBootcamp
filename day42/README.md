# 🎉 Day 42 - Birthday Invite Project

## 📌 Project Overview

This project is part of Day 42 of the Python Bootcamp, where I continued learning HTML by exploring intermediate-level elements. The goal was to create a simple Birthday Invitation webpage using images, lists, hyperlinks, and proper HTML structure.

The project demonstrates how different HTML elements work together to build an attractive and organized webpage.

---

## 🚀 Features

- Created a Birthday Invitation webpage
- Added an image using the `<img>` element
- Used unordered lists to display items
- Created clickable hyperlinks using anchor tags
- Organized content with headings
- Applied proper HTML document structure

---

## 🛠 Technologies Used

- HTML5
- Visual Studio Code
- Live Server

---

## 📚 Concepts Covered

- HTML Boilerplate
- Lists (`<ul>` and `<li>`)
- Nested Elements
- Anchor Tags (`<a>`)
- Image Tags (`<img>`)
- Relative & Absolute Paths
- HTML Attributes
- Semantic Structure

## ▶️ How to Run

1. Open the project folder in Visual Studio Code.
2. Open the `index.html` file.
3. Install the Live Server extension.
4. Click **Go Live** to preview the webpage.
