# 📝 Building Advanced Forms with Flask-WTF


## 📌 Project Overview

This project was completed as part of **Day 61 of the 100 Days of Python Bootcamp**, focusing on building advanced and secure web forms using **Flask-WTF** and **WTForms**.

The primary goal was to understand how to create reusable forms, validate user input, and protect applications against CSRF attacks while integrating forms with Flask templates and Bootstrap for a better user experience.

# 🎯 Project Goals

The objectives of this project were to:

* Learn how Flask-WTF simplifies form creation.
* Create reusable forms using WTForms.
* Validate user input with built-in validators.
* Understand CSRF protection in Flask applications.
* Integrate Bootstrap styling with Flask forms.
* Build interactive and secure web pages.
