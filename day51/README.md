# 🌐 Day 51 – Internet Speed Monitor

## 📌 Project Overview

This project automates an internet speed test using Selenium WebDriver. The application opens Speedtest.net, runs a speed test, extracts the download and upload speeds, and compares the results with user-defined expected speeds.

The project demonstrates browser automation, dynamic web interaction, and data extraction using Selenium.

---

## 🚀 Features

- Launches Chrome automatically
- Opens Speedtest.net
- Starts the speed test
- Extracts download speed
- Extracts upload speed
- Compares results with expected internet speed
- Displays whether the connection meets the expected performance
