# Day 57 - Templating with Jinja in Flask

## Overview

This project demonstrates how to use the Jinja templating engine in Flask to create dynamic web pages. Instead of writing static HTML, data is passed from Python to templates and rendered dynamically.

## Features

- Flask Routing
- Jinja Template Engine
- Dynamic Variables
- Random Number Generation
- Current Year Display
- Blog Page
- Loop Through Data
- Dynamic HTML Rendering

## How to Run

1. Install Flask

```
pip install flask
```

2. Run the application

```
python app.py
```

3. Open your browser

```
http://127.0.0.1:5000/
```
