# 🌐 Day 54 - Introduction to Flask

## Overview

This project marks the beginning of web development with Python using Flask. It demonstrates how to create a simple web server, define routes, and return HTML responses to users through a browser.

## Features

- Flask web server
- Home page
- About page
- Contact page
- Dynamic URL routing
- Debug mode enabled

## Technologies Used

- Python
- Flask

## Project Structure

```
day54/

```

## Installation

```bash
pip install Flask
```

## Run

```bash
python main.py
```

Then open:

```
http://127.0.0.1:5000
```
