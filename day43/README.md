# 🎨 Day 43 - Introduction to CSS

## 📌 Project Overview

This project marks the beginning of learning CSS (Cascading Style Sheets) in the Python Bootcamp. The goal was to understand how CSS is used to style HTML webpages and improve their appearance.

As part of this lesson, I created a simple Color Vocabulary website where different colors are displayed using CSS classes and images. This project demonstrates how HTML and CSS work together to create visually appealing webpages.

## ▶️ How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Make sure `style.css` is linked correctly.
4. Click **Go Live** using the Live Server extension.
