# 🎨 Day 44 - Intermediate CSS

## 📌 Project Overview

This project is part of Day 44 of the Python Bootcamp, where I explored intermediate CSS concepts to improve the design and layout of web pages. The lessons focused on colors, typography, spacing, browser developer tools, and the CSS Box Model.

To apply these concepts, I built a Motivational Poster webpage by styling HTML elements with CSS, creating a clean layout, and improving the overall visual appearance of the webpage.

2. Open `index.html`.
3. Ensure the CSS file is linked correctly.
4. Click **Go Live** using the Live Server extension.
