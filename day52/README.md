# 📸 Day 52 - Instagram Profile Analyzer

## 📌 Project Overview

This project demonstrates browser automation using Selenium WebDriver by navigating to an Instagram profile and extracting publicly visible profile information. It focuses on learning Selenium techniques such as browser control, waiting for dynamic content, and locating page elements.

> **Educational Note:** This project is intended for learning browser automation. It does not automate following users, liking posts, or sending messages.

---

## 🚀 Features

- Launches Chrome automatically
- Opens an Instagram profile
- Reads publicly visible profile information
- Demonstrates Selenium automation
- Uses explicit waits for dynamic content
