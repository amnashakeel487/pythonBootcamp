# 📊 Day 37 – Habit Tracker with Pixela API

## 📌 Project Overview

On Day 37 of the **100 Days of Python Bootcamp**, I built a Habit Tracker application using the Pixela API. This project focuses on interacting with REST APIs by creating, updating, and deleting data using different HTTP methods. It demonstrates how to authenticate API requests, manage daily habit records, and automate personal progress tracking.

---

## 🚀 Project Features

- Create a Pixela user account
- Create a custom habit tracking graph
- Add daily habit records
- Update existing habit entries
- Delete habit records
- Authenticate requests using API tokens
- Store sensitive credentials securely using environment variables
