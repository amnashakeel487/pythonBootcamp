# 🎬 Day 41 - Movie Ranking Project

## 📌 Project Overview

The Movie Ranking Project is my first HTML project in the Web Development section of the Python Bootcamp. The goal of this project is to build a simple webpage using only basic HTML elements while learning the structure of an HTML document.

The webpage displays a personal list of favorite movies using headings, paragraphs, and a horizontal line to organize the content.

## 🚀 Features

- Created a complete HTML5 document
- Used heading tags (H1, H2, H3)
- Added descriptive paragraphs
- Organized content using a horizontal rule (`<hr>`)
- Displayed a list of favorite movies in a clean layout

---

## 🛠 Technologies Used

- HTML5
- Visual Studio Code
- Live Server

## 📚 Concepts Covered

- HTML Document Structure
- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<title>`
- `<body>`
- Heading Elements (`<h1>` to `<h3>`)
- Paragraph Element (`<p>`)
- Horizontal Rule (`<hr>`)

## ▶️ How to Run

1. Open the project folder in Visual Studio Code.
2. Open the `index.html` file.
3. Install the Live Server extension (if not already installed).
4. Click **Go Live** to launch the webpage in your browser.
