# 🤖 Day 48 - Selenium WebDriver

## 📌 Project Overview

This project is part of Day 48 of the 100 Days of Python Bootcamp. It introduces Selenium WebDriver, a powerful browser automation framework used to interact with websites just like a human user.

Throughout this day, I learned how to open web pages, locate HTML elements, extract information, click buttons, fill forms, and automate browser-based tasks using Python.

---

## 🚀 Projects Included

### 1. Selenium Browser Practice
- Open a website
- Read the page title
- Close the browser

### 2. Wikipedia Automation
- Extract article statistics
- Locate elements using CSS selectors

### 3. Python.org Event Scraper
- Collect upcoming Python events
- Read and display event information

### 4. Cookie Clicker Bot
- Automatically click the cookie
- Demonstrate browser automation with Selenium
