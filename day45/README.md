# 🌐 Day 45 - Web Scraping with BeautifulSoup

## 📌 Project Overview

This project is part of Day 45 of the Python Bootcamp and introduces Web Scraping using Python. The goal is to learn how to extract information from websites automatically by parsing HTML with the BeautifulSoup library.

The project demonstrates how to download webpage content, locate HTML elements, extract useful information, and save the collected data into a text file.
