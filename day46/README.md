# 🎵 Spotify Musical Time Machine

## 📌 Project Overview

Spotify Musical Time Machine is a Python application that recreates the Billboard Hot 100 playlist from any past date.

The project combines web scraping with BeautifulSoup and Spotify's Web API to automatically search songs and generate a private Spotify playlist.

---

## 🚀 Features

- Scrapes Billboard Hot 100 songs
- Uses BeautifulSoup for HTML parsing
- Connects with Spotify API
- Authenticates using OAuth
- Creates private playlists
- Automatically adds songs to playlist

---

## 🛠 Technologies Used

- Python
- BeautifulSoup4
- Requests
- Spotipy
- Spotify Web API
- dotenv
