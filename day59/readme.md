# 📝 Personal Blog Website - Bootstrap Styled Flask Blog

## 📌 Project Overview

This project is a **responsive personal blog website** built using **Flask, HTML, CSS, and Bootstrap**.

This project was developed as part of my **100 Days of Python Bootcamp journey (Day 59)**, where I improved the previously created Flask blog website by adding a professional frontend design using the Bootstrap framework.

The main goal of this project was to learn how to combine **backend development with frontend styling** and create a clean, responsive user interface.

# 🎯 Project Goals

The objectives of this project were:

* Style a Flask website using Bootstrap
* Create a responsive blog layout
* Improve UI/UX design
* Understand Bootstrap components
* Connect Flask backend with frontend templates
* Practice professional website structure

# ✨ Features

## 🏠 Home Page

* Displays all blog posts dynamically
* Clean card-based layout
* Responsive design for different screen sizes

## 📄 Blog Post Pages

* Individual page for each blog post
* Dynamic content rendering using Flask routes
* Organized article structure

## 🧭 Navigation Bar

* Easy navigation between pages
* Mobile-friendly menu

* Bootstrap cards
