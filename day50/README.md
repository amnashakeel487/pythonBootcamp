# 🤖 Day 50 - Selenium Browser Automation

## 📌 Project Overview

This project demonstrates browser automation using Selenium WebDriver. The script opens a browser, fills out a web form, interacts with different page elements, and submits the form automatically.

The goal of this project is to practice browser automation techniques that can be applied to testing, productivity tools, and workflow automation.

## 🚀 Features

- Launches Chrome automatically
- Opens a website
- Fills text fields
- Enters passwords
- Writes into text areas
- Clicks buttons
- Uses Explicit Waits
- Demonstrates Selenium automation
