# 🐶 TinDog - Responsive Bootstrap Landing Page

![TinDog Banner](screenshots/tindog-preview.png)

## 📌 Project Overview

**TinDog** is a modern and responsive landing page built using **HTML, CSS, and Bootstrap 5**.

This project was developed as part of my **100 Days of Python Bootcamp journey (Day 58)** to strengthen my understanding of **Web Development Foundations, Responsive Design, and Bootstrap Framework**.

The idea behind TinDog is a fictional platform where dog owners can find and connect with other dogs nearby, similar to a dating application concept.

The main focus of this project was not backend functionality, but learning how professional websites are structured and designed using modern frontend tools.
